## 验证限制

pi 上没有可用的浏览器测试工具，尚未完成真实浏览器中的页面布局、交互和 HTTPS 部署验收；当前依据为页面行为测试与 Vue 构建结果。

pi 上没有 Mermaid 渲染器，远程 SVG 渲染请求返回 HTTP 403；[设计文档](design.md)中的架构图尚未完成渲染验证。

联调使用模拟代理子进程和合成节点，没有验证真实代理核心的网络转发能力。已有线上服务保持运行；实际启用集成仍需配置本机连接及凭证，并按设计文档的部署顺序操作。
