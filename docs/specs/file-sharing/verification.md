## SQL执行计划

在隔离MariaDB10.11中各建立2000条合成文件和分享记录、20个所有者。本人游标列表命中 `idx_files_owner_id`（range，估算90行）；token查找命中 `uk_file_shares_token`（const，1行）；单文件分享列表命中 `idx_file_shares_file_id`（ref，1行）；用户容量聚合命中 `idx_files_owner_id`（ref，估算100行）。该结果证明所核对查询没有全表扫描；容量聚合仍按用户文件数线性读取，受每用户文件数上限约束。
